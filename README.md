# Trail Calendar 2026 y 2027

Calendarios estáticos de carreras de trail desde Grenoble.

- `index.html`: calendario original de 2026.
- `2027.html`: selección 2027, inicialmente Matheysins y SkyRace du Rif Bel (25 km).

Abre cualquiera de los HTML en local o consulta GitHub Pages. Cada página enlaza la otra edición. Los datos y filtros están contenidos en el propio HTML.

Datos de 2027 consultados el 3 de noviembre de 2026 en las fuentes oficiales enlazadas. Matheysins sigue mostrando 2026: su fecha e inscripción 2027 están pendientes y sus 25 km / 1.950 m D+ son referencia de 2026. El programa oficial del Rif Bel anuncia salida el 3 de julio de 2027 a las 09:00.
